# 📧 Spam Email Detection System

A machine learning-based web application built with **Python and Django** to detect whether an email or text message is **Spam** or **Ham (Legitimate)**.

The system uses **Natural Language Processing (NLP)** techniques such as text cleaning, tokenization, stop-word removal, and lemmatization to preprocess the input text. The processed text is converted into numerical features using **TF-IDF (Term Frequency–Inverse Document Frequency)** and then classified using machine learning algorithms such as **Logistic Regression** and **Multinomial Naive Bayes**.

The application provides a simple web interface where users can enter email content and receive a **Spam/Ham prediction along with a confidence score**. It also stores prediction results in a database, allowing users to view and search their previous detection history.

### 🔑 Key Technologies

**Python • Django • Machine Learning • NLP • TF-IDF • Scikit-learn • NLTK • Pandas • NumPy • SQLite**
